# Kaggle - Intermediate Machine Learning

This repo contains the Jupyter Notebook I completed during Kaggle's "Intermediate Machine Learning" course.

## What's in this Notebook?

* **Handling Missing Values:** Dealing with missing data strategically for machine learning models using `SimpleImputer`.
* **Categorical Variables:** Converting categorical text data into numerical formats using `OrdinalEncoder` and `OneHotEncoder`.
* **Pipelines:** Streamlining data preprocessing and modeling steps into a single, clean workflow using `Pipeline` and `ColumnTransformer` to prevent train-test contamination.
* **Cross-Validation:** Measuring model performance more accurately and robustly across multiple folds using `cross_val_score`.
* **Gradient Boosting (XGBoost):** Building and optimizing highly accurate ensemble models using `XGBRegressor`, and tuning hyperparameters like `n_estimators`, `learning_rate`, and `early_stopping_rounds`.
* **Data Leakage:** Identifying and preventing target leakage and train-test contamination to ensure models generalize well to new, real-world data.
